아이폰에서 PDF를 보는 방법은 크게 세 가지입니다. ① 기본 '파일' 앱에서 바로 열기, ② 카카오톡·이메일 등에서 첨부파일 미리보기, ③ 전용 뷰어 앱 사용. 대부분의 경우 앱 설치 없이도 바로 볼 수 있습니다.

---

## 1. 아이폰 기본 파일 앱으로 PDF 바로 열기

아이폰에는 '파일(Files)' 앱이 기본으로 설치되어 있습니다. 따로 앱을 받지 않아도 PDF를 즉시 열 수 있는 가장 빠른 방법입니다.

**단계별 방법:**

1. 홈 화면에서 **파일** 앱을 실행합니다.
2. **iCloud Drive** 또는 **내 iPhone** 탭에서 PDF 파일을 찾습니다.
3. 파일을 한 번 탭하면 바로 미리보기가 열립니다.

페이지 이동, 핀치로 확대/축소, 공유까지 기본 기능은 모두 지원합니다. 간단한 확인 용도라면 이 방법이 가장 간편합니다.

### PC에서 받은 PDF를 아이폰으로 옮기는 법

| 방법 | 특징 |
|---|---|
| **AirDrop** | 같은 Wi-Fi 환경에서 가장 빠름 |
| **카카오톡 파일 전송** | PC·모바일 모두 카카오톡 설치 필요 |
| **이메일 첨부** | 용량 제한 있음 (보통 25MB) |
| **iCloud Drive** | 자동 동기화, 인터넷 필요 |

## 2. 카카오톡·이메일로 받은 PDF 파일 보는법

일상에서 가장 흔한 상황입니다. 저장 없이 바로 볼 수 있어 편리합니다.

### 카카오톡에서 열기

1. 채팅방에서 PDF 파일을 탭합니다.
2. 카카오톡 내장 뷰어로 자동으로 열립니다.
3. 오른쪽 상단 **더보기(···)** → **파일로 저장**을 누르면 파일 앱에 보관됩니다.

### 이메일(Mail 앱)에서 열기

- 첨부파일 아이콘을 탭하면 즉시 미리보기가 실행됩니다.
- 길게 누르면 **'파일에 저장'** 옵션이 나타납니다.

### Safari 웹 브라우저에서 열기

- PDF 링크를 탭하면 Safari 안에서 바로 열립니다.
- **공유 버튼(□↑)** → **파일에 저장** 으로 내려받을 수 있습니다.

## 3. 기본 앱으로 안 열릴 때 — 전용 PDF 뷰어 앱 사용

기본 파일 앱만으로 해결이 어려운 경우가 있습니다.

- 암호(비밀번호)가 설정된 PDF
- 100페이지 이상의 대용량 문서
- PDF와 함께 **HWP, DOCX, XLSX** 등 다른 형식도 함께 다뤄야 할 때

이런 상황에는 **OpenDocs** 같은 전용 문서 뷰어 앱이 유용합니다. PDF는 물론 HWP, DOCX, XLSX까지 하나의 앱에서 열 수 있어, 형식마다 다른 앱을 찾아 설치하는 번거로움을 줄여줍니다. 무료로 사용할 수 있다는 것도 장점입니다.

## PDF 파일 저장·관리 팁

파일을 체계적으로 관리하면 나중에 다시 찾을 때 훨씬 편합니다.

- **폴더 분리**: 파일 앱에서 '업무', '개인', '영수증' 등 폴더를 만들어 분류하세요.
- **iCloud 동기화**: iCloud Drive에 저장하면 아이패드·맥에서도 같은 파일을 바로 열 수 있습니다.
- **오프라인 보관**: 인터넷 없이 봐야 하는 파일은 '내 iPhone'에 별도로 저장해두세요.
- **불필요한 파일 정리**: 카카오톡으로 받은 PDF는 따로 저장하지 않으면 대화방 삭제 시 함께 사라집니다.

## 자주 묻는 질문

**Q. 아이폰에서 PDF 파일을 편집할 수 있나요?**
기본 파일 앱에서는 서명 추가, 텍스트 강조 정도만 가능합니다. 텍스트 직접 수정은 별도 편집 앱이 필요합니다.

**Q. PDF가 열리지 않을 때는 어떻게 하나요?**
파일이 손상되었거나 암호가 설정된 경우입니다. 먼저 PC에서 열어 파일 자체에 문제가 없는지 확인해보세요. 암호가 있다면 비밀번호 입력 창이 뜨거나, 뜨지 않는다면 전용 뷰어 앱을 써보세요.

**Q. 용량이 큰 PDF가 너무 느리게 열려요.**
기본 앱은 대용량 파일에서 느려지는 경우가 있습니다. OpenDocs처럼 렌더링 최적화가 된 전용 앱을 사용하면 속도가 개선될 수 있습니다.

**Q. PDF 여러 개를 한꺼번에 관리하고 싶어요.**
파일 앱의 폴더 기능을 활용하거나, OpenDocs처럼 다양한 문서 형식을 한 곳에서 관리할 수 있는 앱을 쓰는 것이 편리합니다.
